    内容を直すときは、このページからもう一度送ってください。

    このあとの流れ
    1. 運営が確定 → トークでご連絡します
    2. トークで「登録」と送る → 料金のご案内と、お店の登録ページのリンクが届きます
    3. 登録ページで、お店のことを5つの画面で入力（約10分）
    4. 最後の画面から、スタッフをLINEで招待
